# supabase/migrations

Espejo **opcional** para quien use el CLI de Supabase. La **fuente de verdad pegable** son los
archivos numerados en `../../.docs/migrations/` (diseñados para pegar tal cual en el editor SQL).

Si usás el CLI: copiá acá cada `000N_*.sql` con el timestamp que espera el CLI, manteniéndolos
sincronizados con `.docs/migrations/`.
